# Video demo 30 detik: Kasku (Reels / TikTok / Shorts)

Disusun dengan skill **video-content-strategist** (Mode 2, short-form).

**Kesimpulan:** satu ide saja, yaitu *menagih kasbon tanpa canggung*. Fitur lain cukup disebut sekilas. Rekaman layar HP vertikal 9:16, tanpa aktor. Teks di layar selalu ada karena sebagian besar penonton menonton tanpa suara.

| | |
|---|---|
| ICP | Pemilik warung atau toko kecil yang masih pakai buku kasbon tulis |
| Format | 9:16, 1080×1920, 30 detik, teks besar (≥ 64px) di area aman tengah |
| Bahan | Rekaman layar Kasku dengan data contoh (Pak Budi, Bu Ani, Mbak Rina) |
| Musik | Instrumental ringan, bebas royalti, volume rendah |
| Keyakinan | Struktur: *verified* (praktik short-form). Performa: *assumed*, belum diuji. |

## Adaptasi per platform
- **TikTok / Reels:** hook harus sudah tampil di frame pertama, tanpa kartu judul. Caption: "Buku kasbon digital gratis untuk warung 📒 #warung #umkm #kasbon".
- **YouTube Shorts:** judul memuat kata kunci long-tail, misalnya **"Cara catat kasbon warung di HP (gratis)"**. Kalimat yang sama diucapkan di 3 detik pertama.
- **Jadwal:** rilis bertahap, jangan di hari yang sama di semua platform.
